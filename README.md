# Very Mini Metro

역을 연결하고 열차를 운행하는 브라우저 게임입니다. Mini Metro의 시스템과 도시별 규칙을 참고한 독립 구현이며 원작 코드·이미지·음원은 사용하지 않습니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
npm test
```

기본 포트는 3000이며 `PORT`로 바꿀 수 있습니다.

## 시작과 진행

시작화면에서 **시작** → **도시 선택** → **시작** 순서로 게임에 들어갑니다. 런던·파리·뉴욕만 처음부터 해금되어 있습니다. 잠긴 도시는 조건을 확인할 수 있지만 일반·무한·크리에이티브 어느 모드에서도 바로 시작할 수 없습니다.

일반 모드에서 도시별 수송 목표를 달성하면 다음 도시가 열립니다. 예를 들어 기본 세 도시 중 하나에서 200명을 수송하면 바르샤바가 열립니다. 별도 챌린지를 달성하면 해당 도시의 익스트림 모드가 열립니다. 해금은 실제 수송 점수와 운행 조건으로 판정하고 저장합니다. 무한·익스트림·크리에이티브·이전 직접 설계 게임의 점수로 일반 모드 진행을 해금하지 않습니다.

**이어서 하기**는 진행 중인 게임을 복구합니다. 도시·모드별 최고 기록과 해금도 유지합니다. 일반 게임 종료 시 같은 네트워크를 무한·크리에이티브로 이어갈 수 있습니다.

### 모드와 보상

- **일반·익스트림:** 하루는 1배속 30초입니다. 매주 일요일에 열차 1대(홍콩은 2대)와, 무작위 추가 자산 두 개 중 하나를 받습니다. 자산을 고르는 동안 시간이 멈추며, 저장 후 복구해도 보상을 중복 지급하지 않습니다.
- **오사카:** 기본 보상으로 일반 열차 2대 또는 신칸센 1대를 고른 뒤 추가 자산 하나를 선택합니다. **도쿄**는 시작 신칸센 1대와 신칸센 추가 보상을 지원합니다.
- **도시별 보상:** 터널·다리 수량은 도시별 설정을 따릅니다. 뭄바이는 객차를 2개씩 받고, 샌프란시스코에서는 교차역을 제공하지 않습니다. 최대 노선 수에 도달하면 새 노선을 보상 후보에서 제외합니다.
- **익스트림:** 한 번 그은 노선은 끝 연장만 허용하고 단축·폐쇄·중간 수정 및 열차·객차 재배치를 금지합니다. 새 역의 위치를 미리 보여줍니다.
- **무한:** 혼잡에 따른 게임 오버가 없고 오래된 대기 승객부터 정리합니다. 하루 수송 효율에 따라 최대 14번 보상을 받습니다.
- **크리에이티브:** 자산은 무제한이며 도시별 노선·열차 한도는 유지됩니다. 역은 자동 생성하지 않으며 지도 편집으로 직접 배치·변경·삭제합니다. 점수 기록과 도시 해금은 하지 않습니다.

### 게임 방법

시작화면 또는 설정의 **게임 방법**에서 목적지 도형, 드래그 노선 편집, 열차·객차·터널, 혼잡, 보상·해금을 그림과 함께 단계별로 확인할 수 있습니다. 첫 플레이에서는 첫 노선을 그리기 전 시간이 흐르지 않고 조작 안내를 표시합니다. 첫 승객을 수송하면 안내를 마치며, ×로 건너뛸 수도 있습니다.

## 조작

- 역을 누른 채 다른 역까지 드래그해 노선을 만듭니다. 한 번의 드래그로 여러 역을 지나가면 차례로 연결되며, 선로가 역에 맞춰 붙는 모습을 미리 표시합니다. 오른쪽 색상으로 노선을 선택할 수도 있습니다. 기존 노선의 중간역에서 새 노선을 시작하면 빈 노선을 자동 선택합니다.
- 선로를 새 역으로 드래그하면 중간에 역을 넣습니다. 선택한 노선의 중간역에 표시되는 작은 색상 손잡이를 다른 역으로 끌면 교체하고, 같은 노선의 기존 역에 놓으면 두 역의 순서를 바꿉니다. 빈 지도에 놓으면 물리적인 역을 지우지 않고 그 노선에서만 제외합니다. 편집 손잡이에서 `Delete`로도 제외할 수 있습니다. 빈 공간에 놓거나 자원이 부족한 연결은 전체 취소하며, 중간에 남은 선로·열차 자산을 만들지 않습니다. 끝역의 T 손잡이로 연장·단축하며, 양 끝역을 연결하면 순환선이 됩니다. 달리던 열차는 기존 다음 역까지 도착한 뒤 승객을 내리고, 열차·객차를 유지한 채 변경 노선에 재배치됩니다. 폐쇄한 노선의 열차는 회수합니다. 익스트림에서는 중간 편집을 허용하지 않습니다.
- 열차를 선로 위에 놓고 객차를 열차에 끌어 붙입니다. 운행 중인 열차를 다른 선로로 옮기면 다음 역에서 승객을 내린 뒤 이동합니다. 열차를 클릭하면 관리창이 열립니다.
- 날짜·시계를 누르면 1배속 → 2배속 → 일시 정지가 순환합니다. `Space`로도 일시 정지합니다.
- `1`–`7` 노선 선택, `D` 그리기, `Esc` 도구 취소. 빈 지도를 드래그해 이동하고 +/−/⌖로 확대·축소·맞춤합니다.
- 주간 자산 보상은 운행 상황에 맞게 선택합니다. 음향·색상·전체 화면 설정은 상단 설정에서 변경합니다.

일반·익스트림·무한 모드에서는 새 역이 개수 제한 없이 계속 생성됩니다. 기본 간격은 24초이며 도시에 따라 다릅니다. 공간이 부족해지면 생성 범위를 넓히고, 배치에 실패하면 1초 뒤 다시 시도합니다. 설계 중·일시 정지·보상 선택·게임 종료 중에는 시간이 흐르지 않습니다.

## 구현과 검증

`simulation.js`는 수송·환승·혼잡·자산·역 생성을, `maps.js`는 34개 도시의 지형·초기 자산·정원·진행 목표를 관리합니다. `game.js`는 화면과 드래그 조작, 저장을 담당합니다. 테스트는 승객 보존, 열차 재배치, 노선 편집, 도시별 규칙, 무제한 역 생성과 저장 데이터 검증을 포함합니다.

지도는 참고 썸네일을 바탕으로 직접 그린 간략화된 지형입니다. 정확한 원작 좌표나 밸런스는 아닙니다. 문서에 없는 생성 분포·혼잡 타이머·일부 초기 자산·도시 연결 등은 자체 기본값입니다. 온라인 랭킹·빈티지 지도·창작마당은 제공하지 않습니다. 기본 세 도시의 1000명 수송 메달은 저장하지만 빈티지 지도를 구현한 것은 아닙니다. 원작의 정확한 생성 확률·지리 좌표·일부 맵의 미기재 조건을 재현했다고 주장하지 않습니다.

## 로딩

시작 버튼은 게임 초기화가 끝난 뒤 활성화합니다. HTML·CSS·JavaScript에 버전 식별자를 사용하며 Node 서버는 `Cache-Control: no-store`로 응답해 이전 모듈이 섞이는 문제를 예방합니다. 파일 로딩이 실패하면 시작화면에 새로고침 안내를 표시합니다.
