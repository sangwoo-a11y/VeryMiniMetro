# Very Mini Metro

역을 연결하고 열차를 운행하는 브라우저 게임입니다. Mini Metro의 시스템과 도시별 규칙을 참고한 독립 구현이며 원작 코드·이미지·음원은 사용하지 않습니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
npm test
```

기본 포트는 3000이며 `PORT`로 바꿀 수 있습니다.

## 시작과 진행

시작화면에서 도시를 고른 뒤 **시작**을 누릅니다. 34개 도시를 모두 선택할 수 있습니다. 난이도는 일반 모드, 역은 자동 배치·생성, 도전 조건 자동 정지는 끄기로 고정합니다.

최근에 플레이한 도시를 선택 기본값으로 기억합니다. 도시는 자동으로 넘어가지 않으며, 다시 시작하면 같은 도시에서 새 게임을 만듭니다. **이어서 하기**는 진행 중인 게임을 복구하며, 이전 버전의 설계·다른 모드 저장 데이터도 유지합니다. 최고 기록·해금·최근 도시는 브라우저에 저장합니다.

## 조작

- 역을 누른 채 다른 역까지 드래그해 노선을 만듭니다. 한 번의 드래그로 여러 역을 지나가면 차례로 연결되며, 선로가 역에 맞춰 붙는 모습을 미리 표시합니다. 오른쪽 색상으로 노선을 선택할 수도 있습니다. 기존 노선의 중간역에서 새 노선을 시작하면 빈 노선을 자동 선택합니다.
- 선로를 새 역으로 드래그하면 중간에 역을 넣습니다. 빈 공간에 놓거나 자원이 부족한 연결은 전체 취소하며, 중간에 남은 선로·열차 자산을 만들지 않습니다. 끝역의 T 손잡이로 연장·단축하며, 양 끝역을 연결하면 순환선이 됩니다.
- 열차를 선로 위에 놓고 객차를 열차에 끌어 붙입니다. 운행 중인 열차를 다른 선로로 옮기면 다음 역에서 승객을 내린 뒤 이동합니다. 열차를 클릭하면 관리창이 열립니다.
- 날짜·시계를 누르면 1배속 → 2배속 → 일시 정지가 순환합니다. `Space`로도 일시 정지합니다.
- `1`–`7` 노선 선택, `D` 그리기, `Esc` 도구 취소. 빈 지도를 드래그해 이동하고 +/−/⌖로 확대·축소·맞춤합니다.
- 주간 자산 보상은 운행 상황에 맞게 선택합니다. 음향·색상·전체 화면 설정은 상단 설정에서 변경합니다.

새 역은 개수 제한 없이 계속 생성됩니다. 기본 간격은 24초이며 도시에 따라 다릅니다. 공간이 부족해지면 생성 범위를 넓히고, 배치에 실패하면 1초 뒤 다시 시도합니다. 설계 중·일시 정지·보상 선택·게임 종료 중에는 시간이 흐르지 않습니다.

## 구현과 검증

`simulation.js`는 수송·환승·혼잡·자산·역 생성을, `maps.js`는 34개 도시의 지형·초기 자산·정원·진행 목표를 관리합니다. `game.js`는 화면과 드래그 조작, 저장을 담당합니다. 테스트는 승객 보존, 열차 재배치, 노선 편집, 도시별 규칙, 무제한 역 생성과 저장 데이터 검증을 포함합니다.

지도는 참고 썸네일을 바탕으로 직접 그린 간략화된 지형입니다. 정확한 원작 좌표나 밸런스는 아닙니다. 문서에 없는 생성 분포·혼잡 타이머·일부 초기 자산·도시 연결 등은 자체 기본값입니다. 온라인 랭킹·빈티지 지도·창작마당은 제공하지 않습니다.

참고: [Mini Metro/시스템](https://namu.wiki/w/Mini%20Metro/%EC%8B%9C%EC%8A%A4%ED%85%9C), [Mini Metro/맵](https://namu.wiki/w/Mini%20Metro/%EB%A7%B5). 문서 본문과 원본 이미지는 배포 파일에 포함하지 않습니다.

## 로딩

시작 버튼은 게임 초기화가 끝난 뒤 활성화합니다. HTML·CSS·JavaScript에 버전 식별자를 사용하며 Node 서버는 `Cache-Control: no-store`로 응답해 이전 모듈이 섞이는 문제를 예방합니다. 파일 로딩이 실패하면 시작화면에 새로고침 안내를 표시합니다.
