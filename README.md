# Very Mini Metro

서울 한강을 배경으로 역을 연결하고 승객을 수송하는 작은 브라우저 게임입니다. 원작의 에셋을 사용하지 않은 독립적인 구현입니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT` 환경 변수로 변경할 수 있습니다. `npm test`로 경로 탐색, 승객 수송, 환승, 시뮬레이션과 노선 편집을 검증합니다.

## 조작

- 1–3 또는 하단 버튼으로 노선을 선택하고 역을 순서대로 클릭해 확장합니다.
- 연결된 노선 끝에서 다른 역까지 드래그해 확장할 수도 있습니다.
- 승객은 자신의 도형과 같은 역에서 내립니다. 연결된 노선을 통해 자동으로 환승합니다.
- 노선당 열차 한 대, 정원 6명. 45초마다 새 역이 등장하며 최대 12개 역까지 성장합니다.
- 대기 승객이 8명 이상인 역은 붉게 표시됩니다. Endless 모드이므로 게임이 종료되지는 않습니다.
- Space로 일시 정지하고 1× 버튼으로 속도를 변경합니다. Reset line은 선택한 노선을 비우며 탑승 승객도 초기화합니다.
- 모든 상태는 메모리에 저장되므로 새로고침하면 새 게임이 시작됩니다.

글꼴은 Google Fonts를 사용할 수 있을 때 불러오며, 오프라인에서는 시스템 글꼴로 작동합니다.
