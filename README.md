# Very Mini Metro

브라우저에서 노선을 설계하고, 열차·객차를 배치하고, 승객을 수송하는 독립적인 지하철 운영 게임입니다. 제공된 **Mini Metro/시스템** 및 **Mini Metro/맵** 문서를 참고해 시뮬레이션을 다시 구성했습니다. 원작의 코드·이미지·음원은 사용하지 않습니다.

## 기본 플레이: 지도를 직접 조작

시작화면의 **시작하기**로 도시를 고르면 자동으로 배치된 기본 역에서 시작합니다. 역 사이를 드래그하면 노선이 생기고 열차가 자동 투입됩니다. 도시는 승객과 역이 늘면서 확장됩니다.

- 선로 구간을 잡아 새 역으로 드래그하면 중간에 삽입됩니다. 클릭 후 역을 누르는 기존 조작도 지원합니다.
- 끝역의 T 손잡이는 노선 방향을 따라 표시됩니다. 밖으로 끌어 연장하고, 중간역으로 되돌려 끌면 단축합니다. 반대 끝역으로 연결하면 순환선이 됩니다.
- 하단 열차 자산을 선로 위에 놓으면 **놓은 위치**에서 운행을 시작합니다. 객차 자산은 열차 위로 끌어 연결합니다.
- 운행 중인 열차도 다른 선로로 끌어 재배치할 수 있습니다. 다음 역에서 승객을 내린 뒤 목표 선로의 지정 위치로 옮깁니다. 클릭하면 관리창을 사용할 수 있습니다.
- 오른쪽에서 노선을 선택하고, 우측 위에서 수송 실적과 날짜를 확인합니다. 터널은 물 위를 통과하는 부분에 점선으로 표시합니다. 겹친 노선은 색이 보이도록 나란히 표시합니다.
- 화면은 지도 중심으로 구성하며, 역 이름과 상시 격자를 숨깁니다. 역 직접 설계와 지도 편집은 별도로 선택합니다. 지도 조작을 하는 동안 시뮬레이션이 잠시 멈춥니다.

## 선택 기능: 역부터 직접 설계

시작화면의 **시작하기** → 도시 선택에서 **역부터 직접 설계** 활성화 → **설계 시작**으로 빈 지도에 들어갑니다. 직접 설계에서는 모든 도시를 사용할 수 있습니다.

1. **역 배치 / 모양 변경** 도구와 모양을 선택하고 빈 땅을 눌러 역을 놓습니다. 물 위나 다른 역에 너무 가까운 위치는 허용하지 않습니다.
2. **역 이동**을 선택한 뒤 역을 드래그해 위치를 조정합니다. 이동은 운행 시작 전에만 가능합니다. 연결된 선로도 함께 바뀌며 터널 수량을 초과하는 이동은 취소됩니다.
3. **노선 연결**로 전환하고 역 사이를 드래그하거나 역을 차례로 누릅니다. 설계 도중 노선과 역을 지우고 다시 배치할 수 있습니다. 연결된 역을 삭제하려면 먼저 그 역의 노선을 제거합니다.
4. 원·세모·네모 역을 각각 하나 이상 배치하고, 모든 역을 노선이나 환승으로 연결한 후 **운행 시작**을 누릅니다. 열차가 한 대 이상 필요합니다.

설계 단계에서는 시간·승객 생성·열차 운행이 멈춥니다. 역이 하나도 없는 설계도 저장하고 이어서 할 수 있습니다. 운행을 시작하면 직접 설계한 지도에서도 새 역이 자동 생성됩니다. 일반·무한·크리에이티브에서는 역을 추가하거나 모양을 바꿀 수 있습니다. 익스트림은 운행 후 편집 제한을 적용합니다. 직접 설계 기록은 기존 지도 기록과 분리하며 원작 지도·익스트림 해금에는 사용하지 않습니다.

기본 선택은 자동 역 배치·자동 확장 방식입니다. 시작화면의 **이어서 하기**는 이전 버전의 진행 상황도 복구합니다. 상단 로고로 시작화면에 돌아갈 수 있습니다.

## 실행 및 검증

Node.js 20 이상. 외부 패키지 설치나 API 키 없이 실행됩니다.

```sh
npm start
npm test
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`는 실제 수송·환승, 승객 보존, 자산 이동, 혼잡, 주간 보상, 모드 제한, 34개 도시 설정과 저장 데이터 검증을 실행합니다.

## 플레이

1. 자동 생성 방식을 선택한 경우 도시와 모드를 고르고 **운행 시작**을 누릅니다. 런던·파리·뉴욕은 기본 해금입니다. 크리에이티브에서는 모든 도시를 미리 체험할 수 있습니다.
2. 아래의 노선 색을 선택하고 역을 차례로 클릭하거나 역 사이를 드래그합니다. 두 역이 연결되면 보유한 열차가 자동 투입됩니다. 양 끝에서 연장할 수 있고, 끝역끼리 연결하면 순환선이 됩니다.
3. 선로 구간을 누른 다음 새 역을 누르면 중간에 삽입됩니다. **역 빼기**는 선택 노선에서 해당 역을 제거합니다. ×는 선택 노선을 폐쇄합니다. 순환선 옆의 ◡ 버튼으로 순환을 해제할 수 있습니다.
4. **열차**를 선택하고 선택 노선의 역을 누르면 추가 투입됩니다. **객차**를 선택하고 열차를 누르면 연결됩니다. 플랫폼에서 정차 중인 열차에는 해당 역을 눌러서도 객차를 추가할 수 있습니다.
5. 운행 중인 열차를 누르면 열차·객차를 다른 노선으로 옮기거나 회수할 수 있습니다. 열차 이동은 대상 노선과 역, 객차 이동은 대상 열차를 지정합니다. 승객은 기존 노선의 다음 도착역에서 먼저 내립니다. 연결된 객차는 열차와 함께 이동합니다.
6. 물을 통과하는 **역 사이 구간마다** 터널·다리 1개가 필요합니다. 횡단 구간은 점선으로 표시됩니다. 구간 삭제 시 자산이 반환됩니다. 교차역은 정원을 두 배로 늘리고 승하차를 빠르게 하지만 회수할 수 없습니다.

노선 변경 중이던 열차는 기존 구간을 끝까지 운행합니다. 해당 구간은 옅은 점선으로 남고, 다음 역에서 승객을 내린 뒤 유효한 노선에서 계속 운행하거나 회수됩니다. 승객을 삭제하거나 이동 도중 다른 역으로 옮기지 않습니다.

### 시간, 수요와 혼잡

- 1배속 기준 하루 30초, 일요일마다 열차와 무작위 자산 2개 중 하나를 받습니다. 1배속·2배속·일시 정지를 지원합니다.
- 문서의 평일·주말 출발지별 수요 표를 적용합니다. 현재 존재하는 모양만 목적지가 되고, 특수역 간 이동은 생성하지 않습니다. 십자 수요와 주말 특수역 수요에 가중치를 줍니다.
- 열차는 거리와 환승 비용을 고려해 목적지 방향 승객을 태웁니다. 도착역에서 목적지와 모양이 같아야 수송 점수가 증가합니다.
- 기본 역 정원은 6명, 서울은 5명, 파리·뭄바이는 4명입니다. **정원을 초과한 상태**가 이어지면 원형 경고가 찹니다. 혼잡을 해소하면 서서히 줄어듭니다.
- 기본 객차당 6인승, 카이로·뭄바이는 4인승입니다. 객차는 문서 기준 최대 65개까지 연결할 수 있습니다. 화면에는 앞 12칸과 생략된 칸수를 표시하며 실제 정원은 전체 객차를 반영합니다.

### 모드

- **일반:** 혼잡 타이머가 끝나면 게임 종료. 수송 점수로 다음 도시와 익스트림 모드를 해금합니다.
- **익스트림:** 끝역 연장·순환선 완성만 허용합니다. 단축·폐쇄·중간 삽입·열차와 객차 재배치는 금지됩니다. 새 역의 위치가 10초 먼저 표시됩니다.
- **무한:** 혼잡에 따른 패배 없이 오래된 대기 승객을 정리합니다. 하루 수송 실적에 따라 최대 14번 보상을 받습니다.
- **크리에이티브:** 자산 무제한, 도시별 노선·열차 한도 유지. 새 역이 자동 생성되며, 빈 땅에 역을 직접 만들고 모양을 바꾸거나 삭제할 수도 있습니다. 특수역은 모양마다 한 개입니다. 삭제하려는 역의 노선과 열차는 먼저 제거해야 합니다.

일반 모드에서 종료한 네트워크를 그대로 무한·크리에이티브로 이어갈 수 있습니다. 도전 조건 자동 정지를 선택하면 조건을 위반했을 때 시간이 멈추며, 편집으로 해결하면 계속됩니다. 일반 모드에서 수송을 시작한 이후 챌린지 조건을 위반하며 운행한 기록은 그 판의 익스트림 해금에서 제외합니다.

### 도시별 설정

34개 도시의 지형과 설정을 `maps.js`에서 관리합니다. 주요 차이를 적용했습니다.

- 서울: 여의도의 사각형 시작역, 5명 정원, 빠른 승하차, 기본역의 특수역 전환.
- 도쿄: 기본 신칸센 1대, 추가 보상에서 낮은 확률로 신칸센 등장. 오사카: 기본 주간 보상으로 열차 2대 또는 신칸센 1대 선택.
- 멜버른: 전차 속도 25% 감소. 홍콩: 기본 주간 열차 2대.
- 뭄바이: 초기 객차 3개, 보상 객차 2개, 역·객차 정원 4명.
- 베를린·부다페스트·산티아고 등 터널 보상 차이, 보스턴 터널 3개 보상, 샌프란시스코 교차역 사용 금지.
- 5개·6개·7개 노선 지도별 열차 한도, 상하이 시작역 5개, 섬과 물 횡단 판정.

## 저장과 설정

진행 상황과 최고 기록·해금·설정은 브라우저 `localStorage`에 3초마다, 편집 후, 탭을 닫기 전에 저장됩니다. 메뉴의 **이어서 하기**로 복구합니다. 저장 공간을 사용할 수 없으면 설정에 안내합니다. 다른 기기나 브라우저로 동기화되지는 않습니다. 야간 모드, 색약 친화 노선색, 효과음과 음량, 전체 화면을 지원합니다. 열차와 승객은 메모리의 게임 상태를 직접 렌더링합니다.

키보드: `Space` 일시 정지 · `1`–`7` 노선 선택 · `D` 그리기 · `Esc` 도구 취소. 역과 열차는 Tab으로 선택해 Enter로 조작할 수도 있습니다. 빈 지도를 드래그하면 이동하고 +/−/⌖로 확대·축소·맞춤합니다.

## 재구성 범위

원작 자체의 정확한 복제는 아닙니다. 지도는 첨부된 썸네일을 참고해 직접 그린 **간략화된 지형**이며 원작 지리 데이터나 좌표를 사용하지 않습니다. 문서에 없는 난수 분포·세부 시간·일부 맵의 초기 자산과 해금 연결은 이 프로젝트의 기본값입니다. 혼잡 타이머는 45초, 역 생성은 기본 24초 간격이며 도시 설정에 따라 달라집니다. 개수 제한 없이 생성 범위가 점차 넓어지며, 배치 위치를 찾지 못하면 1초 뒤 다시 시도합니다. 일시 정지·설계 중·보상 선택 중·게임 종료 상태에서는 생성도 멈춥니다. 수요 증가율, 무한 모드 효율 보상 기준, 신칸센 배율과 교차 감속도 자체 조정값입니다. 정확한 원작 밸런스를 주장하지 않습니다.

빈티지 지도·히든 지도·Steam 창작마당·온라인 데일리 랭킹은 구현하지 않았습니다. 기본 세 도시의 1000명 메달은 저장하지만 빈티지 지도를 제공하지는 않습니다. 참고 문서에 없는 난징·충칭·뭄바이의 익스트림 목표 등은 별도로 보완할 수 있도록 설정을 분리했습니다.

참고: [Mini Metro/시스템](https://namu.wiki/w/Mini%20Metro/%EC%8B%9C%EC%8A%A4%ED%85%9C), [Mini Metro/맵](https://namu.wiki/w/Mini%20Metro/%EB%A7%B5). 규칙과 도시별 수치를 참고했으며 문서 본문과 원본 이미지는 배포 파일에 포함하지 않았습니다.

화면에는 시작·이어하기와 도시·노선·자산·설정 조작만 남겼습니다. 중복 재생·속도·재시작·음향 버튼은 삭제했습니다. 날짜/시계를 누르면 1배속 → 2배속 → 일시 정지가 순환하며 Space로도 멈출 수 있습니다. 음향은 설정에서 바꿉니다.
